    // 04 — academy

    ~/academy

    Learn it before the CTF asks.

    Self-paced learning paths built from our workshops. Pick one, work through it at your own speed, then test yourself in the arena.

    browse all paths ->

    malwarous@qau:~$ tree ~/academy -L 1

    • Web Hacking 101

      HTTP, cookies, sessions and the OWASP Top 10, learned by breaking a deliberately vulnerable app.

      level: beginner[N] modules

    • AI Security Fundamentals

      How LLM apps fail — prompt injection, data leakage, insecure tool use — and how to red-team them.

      level: intermediate[N] modules

    • Linux for CTFs

      The shell, permissions, processes and pipes: the ground every challenge assumes you're standing on.

      level: beginner[N] modules

    • Crypto & Forensics

      From classical ciphers to broken RSA, from file carving to packet captures.

      level: intermediate[N] modules
