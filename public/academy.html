// 04 — field kit

~/academy/kit

malwarous@qau:~$ cat setup.txt

  • A Linux terminal

    WSL on Windows, a virtual machine or a cloud shell. You need somewhere to run commands without fear.

  • A browser with devtools

    Firefox or Chrome. Learn the network panel and the console before you install a single extension.

  • A TryHackMe account

    The arena rooms live there. The free tier is enough to start; the room links are posted with each event.

  • A notebook

    Plain markdown or paper. Write the command, the result and what you thought it meant. Future you will need it.

We only hack with permission.

CTFs, our own labs, and systems we're authorized to test. Nothing else.
