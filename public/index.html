    // 04 — academy

    ~/academy

    Learn it before the CTF asks.

    Our degree courses rebuilt for self-study, plus a cybersecurity journey from your first terminal to your first CTF. Then test yourself in the arena.

    browse all paths ->

    malwarous@qau:~$ tree ~/academy -L 1

    • PSP: Problem Solving and Programming

      The degree course, as video lectures posted as they're released.

      track: degreelectures posting now

    • Linux for CTFs

      The shell, permissions, processes and pipes: the ground every challenge assumes you're standing on.

      track: journeylevel: beginner

    • Web Hacking 101

      Cookies, sessions and the OWASP Top 10, learned by breaking a deliberately vulnerable app.

      track: journeylevel: beginner

    • AI Security Fundamentals

      How LLM apps fail: prompt injection, data leakage, insecure tool use, and how to red-team them.

      track: journeylevel: intermediate
